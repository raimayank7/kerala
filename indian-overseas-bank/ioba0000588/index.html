How the code IOBA0000588 is built

IOBA is the bank part: the letters of Indian Overseas Bank. The fifth character is always the digit 0. 000588 is the part that names this branch.

The MICR code 689020052 is the number printed along the bottom of this branch's cheques. 689 is the city (the same three digits that begin the PIN code 689121), 020 is the bank and 052 is the branch.
