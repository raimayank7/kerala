How the code KSBK0001237 is built

KSBK is the bank part: the letters of Kerala State Co-operative Bank. The fifth character is always the digit 0. 001237 is the part that names this branch.

The MICR code 689177237 is the number printed along the bottom of this branch's cheques. 689 is the city (the same three digits that begin the PIN code 689121), 177 is the bank and 237 is the branch.
