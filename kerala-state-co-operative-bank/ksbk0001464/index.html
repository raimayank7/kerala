How the code KSBK0001464 is built

KSBK is the bank part: the letters of Kerala State Co-operative Bank. The fifth character is always the digit 0. 001464 is the part that names this branch.

The MICR code 680177464 is the number printed along the bottom of this branch's cheques. 680 is the city (the same three digits that begin the PIN code 680581), 177 is the bank and 464 is the branch.
